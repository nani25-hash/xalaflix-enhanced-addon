# 🎬 Xalaflix Enhanced - Stremio Add-on Portal

Xalaflix Enhanced is a maximally optimized Stremio add-on portal featuring a sleek, modern interface, advanced stream discovery, and high-performance indexing.

## 🚀 Features

- **One-Click Installation**: Seamlessly install the add-on to Stremio with a single click.
- **Copy Manifest URL**: Easily copy the direct manifest URL for manual installation or sharing.
- **Modern UI**: Built with React, Tailwind CSS, and Framer Motion for a premium user experience.
- **Stremio V3 Manifest**: Optimized for low latency and fast discovery.
- **Responsive Design**: Works perfectly on desktop and mobile devices.

## 🛠️ Technical Stack

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + Shadcn/UI
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Hosting**: Blink.new
